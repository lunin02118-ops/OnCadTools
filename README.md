# OnCadTools Russian Pro (v3.2.7.0) for SolidWorks

Профессиональная русская локализация и чистая интеграция надстройки **OnCadTools (瓯南CAD工具箱) 3.2.7.0** для SolidWorks 2018–2025.

---

## 🌟 Основные возможности

- **100% Русский интерфейс:**
  - Полный перевод всех вкладок Ribbon CommandManager.
  - Локализация боковой панели TaskPane со всеми кнопками и подсказками.
  - Перевод всех таблиц (DataGridView), колонок, списков форматов, материалов, крепежа и свойств.
  - Локализация диалоговых окон настроек (включая пакетный экспорт чертежей, спецификации, лазерный раскрой и раскрой профилей).
  - Словарь включает **9 589** проверенных машиностроительных терминов и параметров ЕСКД.
- **Detour видовых экранов SolidWorks:**
  - Корректная поддержка русских имён проекций и развёрток (*Спереди, *Сверху, *Справа, *Сзади, *Снизу, *Изометрия, *Развертка) при пакетном экспорте в DXF/DWG/PDF без сбоев поиска видов.
- **Безопасная прозрачная архитектура:**
  - Оригинальное защищённое ядро OnCadTools_Core.dll остаётся нетронутым (без повреждения обфускации и виртуальной машины Agile.NET).
  - Перехват проверки лицензии выполняется в оперативной памяти (JIT detour) через высокопроизводительную сборку-обёртку OnCadTools.dll.
  - Модуль автоматического перевода работает на уровне событий WinForms и Win32 Hooking с кэшированием переводов.

## 🚀 Установка и регистрация

### Способ 1: В 1 клик (Рекомендуется)
1. Запустите от имени Администратора файл:
   `cmd
   Зарегистрировать_OnCadTools.cmd
   `
2. Запустите SolidWorks — надстройка автоматически появится на панели задач справа и во вкладках CommandManager.

### Способ 2: Через PowerShell
Запустите PowerShell от имени Администратора:
`powershell
powershell -ExecutionPolicy Bypass -File .\Register.ps1
`

### Удаление регистрации
Запустите от имени Администратора:
`cmd
Удалить_регистрацию.cmd
`
или
`powershell
powershell -ExecutionPolicy Bypass -File .\Unregister.ps1
`

## 🛠 Сборка из исходников

Для повторной компиляции обёртки и применения изменений в коде:

1. Отредактируйте исходный код при необходимости:
   - src/SimpleAddinWrapper.cs — логика обёртки, JIT detours, перехватчик интерфейса.
   - 	ools/native_dict.tsv — словарь терминов (формат: Оригинал<TAB>Перевод).
2. Запустите скрипт сборки:
   `powershell
   powershell -ExecutionPolicy Bypass -File .\build.ps1
   `
   Скрипт скомпилирует OnCadTools.dll через 64-битный csc.exe и зарегистрирует через egasm.exe.

## 📁 Структура репозитория

`
OnCadTools/
├── src/
│   └── SimpleAddinWrapper.cs    # Исходный код обёртки, активатора и переводчика
├── tools/
│   ├── native_dict.tsv          # База перевода терминов (9 589 записей)
│   └── NativeRusifier.exe       # Вспомогательный транслятор диалогов
├── 模板/                         # Шаблоны чертежей, форматок и спецификаций
├── 配置/                         # Базы стандартных профилей, крепежа и конфигураций
├── build.ps1                    # Скрипт пересборки OnCadTools.dll
├── Register.ps1                 # Скрипт регистрации COM-сервера
├── Unregister.ps1               # Скрипт удаления регистрации
├── OnCadTools_Core.dll          # Защищённое оригинальное ядро 3.2.7.0
├── OnCadTools.dll               # Скомпилированная обёртка
├── OnCadToolsConfig.ini         # Конфигурация путей
└── README.md                    # Документация проекта
`
